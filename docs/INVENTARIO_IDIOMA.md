# Inventario de adaptación del idioma

Fuente: auditoría AST de pantallas/servicios antes de la adaptación y revisión manual de plantillas/interpolaciones. La auditoría previa incluyó 37 archivos de ejecución con líneas numeradas, entregados antes de aprobación. Este inventario portable conserva los pares de mensajes humanos y las excepciones de contrato; no contiene datos privados ni credenciales.

Los pares siguientes no se aplican como búsqueda/reemplazo a datos del usuario, nombres de campos, rutas o migraciones. El código llama claves explícitas de los catálogos. Los nombres genéricos como “cajas” se traducen solo al presentar conteos; las rutas `/app/cajas` se conservan. Para fuentes y alcance por pantalla, ver INTERNACIONALIZACION.md.

## Interpolaciones y metadatos

Mostrar/Ocultar contraseña usa `{label}`; Retry-After usa `{seconds}`; bienvenida usa `{name}`; acciones accesibles de cajas usan `{identifier}` y categorías `{name}`. Los conteos distinguen box/boxes y category/categories mediante Intl.PluralRules. HTML title/description y lang=en están incluidos. Admin/OPTIONS localizan etiquetas, choices y títulos sin cambiar valores de enums.

## Excepciones deliberadas

Claves `detalle`, `errores`, `campos`, `filtros`, `estado`, `servicio`, `base_de_datos` y valores health `disponible`/`no_disponible`; rutas españolas existentes; prefijo CJ-; metadatos históricos de modelos/migraciones; datos del usuario/DEMO y evidencias F0–F5. Se conservan por contrato, integridad o trazabilidad. Los comentarios previos españoles y nombres históricos de scripts no se renombran por idioma.

No hay selector español completo. Los mensajes nativos del navegador pueden seguir el idioma del navegador; las ayudas propias y errores de aplicación se presentan en inglés.
## Comando de administración académica

La ayuda, los errores de namespace/archivo existente y la confirmación de create_demo se centralizan con las claves inglesas `demo_help`, `demo_namespace`, `demo_exists` y `demo_created`. No cambian argumentos ni datos DEMO españoles, y no se imprimen credenciales.
